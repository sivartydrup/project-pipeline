# UX-D05 · Native shell feasibility recommendation

**Status:** Proposed for owner review, 12 October 2026. **Question:** Can the approved Modern Product Studio shell be implemented in the existing Rust/egui toolkit? **Recommendation:** Yes for layout feasibility at the measured Windows sizes, using a collapsible rail, stacked cards and an assistant drawer at narrow effective widths. Continue with egui under D-009. **Alternative:** Consider another Rust UI toolkit only if production keyboard or screen-reader validation finds a blocking issue that cannot be resolved in egui. **Evidence:** [native spike results](native-spike-results.md) and its ten egui screenshots. **Limits:** End-to-end keyboard focus, AccessKit announcements, formal contrast, narrower widths and M1 Max have not passed. **Impact:** No architecture, domain, approval policy or production UI change is made by this spike. A scoped UX02/UX03 implementation decision remains for the owner.
