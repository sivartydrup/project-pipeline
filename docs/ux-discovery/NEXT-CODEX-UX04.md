## Scope
1. Replace the modern-shell draft-only Guidance panel with a **project-scoped, read-only assistant** that can answer questions about current authorized project data. Preserve compact composer, collapsible panel/narrow drawer, per-project draft isolation, portfolio context, and legacy Advanced tools.
2. Build an explicit, bounded, least-privilege context assembler using `ProjectEngine` read-only APIs. Ground project claims in named persisted record IDs/revisions and distinguish facts, interpretations and unknowns. No raw secret/token exposure, arbitrary file crawling, terminal execution or unsanctioned repository changes. Handle missing/stale evidence conservatively.
3. Integrate with existing supported harness/provider capabilities (inspect OpenCode and Pi adapters). Choose a narrow provider-agnostic conversational interface, reusing established auth/model selection and cancellation patterns when safe. Do **not** silently use a paid model, start a run, install tools, or trigger external effects. Show actual provider/model and any available usage/cost data; never invent costs. Where no safe read-only conversational path exists, document the gap and provide deterministic offline guidance rather than bypassing policy.
4. Stream assistant responses if supported; otherwise clearly indicate buffered response. Support cancel, retry, loading, no-provider, configured-but-unreachable, permission denied, and malformed-response states. Preserve project isolation across in-flight requests and switching. Bound context, output, history and resource usage; avoid background provider calls on mere navigation.
5. Treat project text, agent outputs and provider responses as untrusted. Implement prompt-injection resistance through scoped data and explicit instruction/data separation, redaction, and safe rendering. No conversational response may authorize or execute state changes. Any requested modification must say it requires a future typed proposal and owner review; UX05 is out of scope.
6. Add unit/integration tests with mocked adapters for isolation, correct citations/record IDs, cancellation, failures, stale contexts, cost disclosure, secret redaction, prompt injection and no-mutation invariants. Add Windows native UI evidence for 1024/1440, light/dark, 100/200% zoom, keyboard and AccessKit where feasible. Do not claim live model tests if unavailable.
