# Terminal implementation evidence

P07 adds `TerminalSession` in `pipeline-terminal` and project-scoped tabs in the desktop app. The PTY starts in the selected project's folder; switching projects selects that project's own terminal tab. Closing a tab kills and reaps its shell. The reader uses a 64-chunk bounded channel; each UI frame parses at most 32 KiB per tab, so a noisy command cannot queue unbounded memory or monopolize a frame. The VT parser retains 5,000 rows of scrollback. Shell choice is PowerShell on Windows and the user's shell (with a platform fallback) on macOS/Linux.

Windows checks on 8 October 2026: the PTY test launched a shell in a temporary folder, verified command output from that folder, resized it, and observed clean exit. A 2,000-line command completed while polling in bounded chunks; closing the session reaped the shell. ANSI/Unicode and scrollback parser tests passed. During implementation, replying to a ConPTY cursor query twice caused PowerShell to drop the first character of the next command. The duplicate reply was removed and the exit test passed. `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, and `cargo build -p pipeline-app` passed locally.

The Windows desktop layout was visually checked: portfolio, management, and terminal panels render together, the horizontal splitter drags, and its size persists across an app restart.
